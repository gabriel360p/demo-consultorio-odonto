## 📌 Sobre o projeto

O **Demo Consultório Odonto** é uma landing page institucional criada com foco em clínicas odontológicas que desejam apresentar seus serviços, transmitir profissionalismo e facilitar o contato com novos pacientes.

O projeto busca simular uma solução real entregue para um negócio, utilizando boas práticas de desenvolvimento Front-end, organização de componentes e uma interface adaptada para diferentes dispositivos.

---

## 🎯 Objetivos do projeto

- Criar uma presença digital moderna para uma clínica odontológica;
- Desenvolver uma interface profissional focada em conversão;
- Aplicar conceitos de responsividade e experiência do usuário;
- Criar uma estrutura reutilizável para projetos comerciais;
- Praticar desenvolvimento de interfaces próximas ao mercado real.

---

## ✨ Funcionalidades

- ✅ Página institucional completa;
- ✅ Apresentação dos serviços odontológicos;
- ✅ Seção de informações da clínica;
- ✅ Área de contato;
- ✅ Layout responsivo para dispositivos móveis, tablets e desktops;
- ✅ Navegação otimizada;

## 🧠 Desafios enfrentados

Durante o desenvolvimento, alguns pontos importantes foram trabalhados:

### 📱 Responsividade

Criar uma interface que mantivesse boa experiência em diferentes tamanhos de tela, garantindo que elementos como textos, imagens e seções permanecessem bem distribuídos.

### 🎨 Construção de uma identidade visual

Desenvolver uma interface que transmitisse características comuns ao segmento odontológico:

- confiança;
- profissionalismo;
- limpeza visual;
- facilidade de navegação.

### 🧱 Componentização

Organizar a aplicação utilizando componentes independentes, evitando repetição de código e facilitando futuras alterações.

## 💻 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/gabriel360p/demo-consultorio-odonto.git
```
Acesse a pasta:
```
cd demo-consultorio-odonto
```
Execute os comandos via terminal dentro da pasta do projeto:
```
npm install
npm run dev
```
Acesse no navegador:
http://localhost:5173
