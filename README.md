## 📌 Sobre o projeto



O **Demo Clínica Estética Belezza** é uma landing page institucional desenvolvida para representar uma clínica de estética moderna, apresentando seus serviços, diferenciais e informações importantes para seus clientes.



O projeto foi criado simulando uma solução digital para um negócio real, com foco em transmitir profissionalismo, confiança e uma experiência visual alinhada ao segmento de beleza e estética.



A aplicação utiliza boas práticas de desenvolvimento Front-end, organização de componentes e uma interface adaptada para diferentes dispositivos.



---



## 🎯 Objetivos do projeto



- Criar uma presença digital profissional para uma clínica de estética;

- Desenvolver uma interface moderna focada na apresentação de serviços;

- Aplicar conceitos de UI/UX voltados para negócios reais;

- Construir uma experiência responsiva e agradável para usuários;

- Desenvolver uma solução próxima às necessidades do mercado.

## ✨ Funcionalidades



- ✅ Página institucional completa;

## 🧠 Desafios enfrentados



Durante o desenvolvimento, alguns pontos importantes foram trabalhados:



### 📱 Responsividade



Criar uma experiência consistente em diferentes tamanhos de tela, garantindo que imagens, textos e seções permanecessem bem distribuídos tanto em dispositivos móveis quanto em telas maiores.



### 🎨 Identidade visual



Desenvolver uma interface alinhada ao segmento de estética, transmitindo características como:



- elegância;

- confiança;

- modernidade;

- organização visual.



### 🧱 Componentização



Estruturar os elementos da página em componentes independentes, facilitando futuras alterações e permitindo uma melhor manutenção do projeto.

## 💻 Como executar o projeto



Clone o repositório:



```bash
git clone https://github.com/gabriel360p/demo-clinica-estetica.git
```



Acesse a pasta:



```bash
cd demo-clinica-estetica
```



Execute os comandos via terminal dentro da pasta do projeto:



```bash
npm install

npm run dev
```



Acesse no navegador:



http://localhost:5173
